A travel poster for a place that does not exist: **LUMARIS**, a lagoon town held in one long dusk, where a single Lantern Spire rises out of still water and burns amber against the teal evening while small lantern boats drift below. The poster is drawn from scratch in Python with Pillow — no stock art, no borrowed destination — and promises exactly what a stay there would feel like: slow evenings on the water, under a low amber moon, in a light that never goes out.

## Run it

```sh
python3 main.py
```

`main.py` (standard library only, no network) copies the committed `poster.png` to the output directory as `entry.png` — `$MAKEFUN_OUTPUT_DIR` or `$OUTPUT_DIR` when set, otherwise `/output`.

To redraw the poster from scratch:

```sh
python3 draw_poster.py
```
